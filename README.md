# Coding Quagsire

Wooper's cousin. Quagsire types when you type, the first key starts some lo-fi, and Ctrl+C clears the terminal with a water gun.

Inspired by [Coding Cat](https://hostrider.com/) and [Lofi Girl](https://lofigirl.com/). I also just like Wooper & Quagsire.

## Run it

No build step, no dependencies:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.
